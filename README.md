# Albanian language pack for phpBB

Albanian (`sq`) translation for phpBB 3.3.19, based directly on the canonical
British English language files from phpBB release 3.3.19.

## Installation

Copy the `language` and `styles` directories into the root of a phpBB 3.3.19
installation. Then open the Administration Control Panel and install Albanian
from **Customise > Language packs**.

## Translation principles

- Standard Albanian (`Shqip`) with a formal, consistent interface tone.
- phpBB language keys, placeholders, template variables, HTML, BBCode and URLs
  are preserved from the British English source.
- Every translated file corresponds to its phpBB 3.3.19 English counterpart.
